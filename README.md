# Merge Advisor

Modular Roblox Merge Advisor project.

## Modules

- Core: initialization and state management
- Data: animal and game configuration
- Calculators: income, luck, merge and plot bonuses
- Advisors: merge, enchant and loadout recommendations
- Automation: smart swap and automatic upgrades
- UI: user interface modules
- Tests: calculation and behavior tests

## Development Principles

- Preserve verified game formulas.
- Keep modules independent.
- Do not modify validated merge behavior without evidence.
- Test changes before integration.
